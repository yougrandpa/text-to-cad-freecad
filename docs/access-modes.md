# 权限模式

页面顶部提供三个权限模式，默认自动审批。选择保存在当前浏览器，每次发送时随
`/chat` 的 `access_mode` 提交，服务端在回合开始时固定。回合中切换只影响下次请求。

| 模式 | 查看 / 测量 | 修改 / 构建 / 导出 | Python | 工具审批与限制 |
| --- | --- | --- | --- | --- |
| 自动审批 `auto` | 允许 | 允许 | 禁止 | 普通工具 ASK 自动允许，DENY 和配置的路径限制保留 |
| 仅可读取 `read_only` | 允许 | 禁止 | 禁止 | 仅暴露并执行五个查看工具 |
| 完全访问 `full` | 允许 | 允许 | 允许 | 跳过工具审批与路径策略，Python 不使用应用沙箱 |

只读允许 `ir_get`、`ir_digest`、`ir_list_features`、`geo_view`、`geo_measure`。
即使模型调用未暴露的写工具、导出或导入，后端也会拒绝。不回填 IR 需求、不产生新 IR
版本；预览仍可能生成缓存，会话消息仍会保存。只读答复以 `inspected` 结束，不表示新
模型通过构建或功能验收。

完全访问以服务进程用户身份运行 Python，能够读写该用户可访问的文件及使用网络。
操作系统权限、参数 schema、工具超时、回合/构建检查和最终需求验收仍生效。
Python 输出不能替代 Gate 和 `design_review` 的证据。

模式控制当前回合的模型工具权限，不是 HTTP API 身份认证或跨用户隔离，服务应维持
本地使用。模型的工具参数无法修改权限，只有请求发起者能选择模式。
嵌入式引擎未传 `UserMessage.access_mode` 时继续使用原有静态审批和沙箱策略；
Web `/chat` 默认 `auto`，`privileged_requested=true` 不能单独开启 Python。

待审批查询支持 `GET /approvals?thread_id=...`，页面只显示当前会话的记录。
事件显示权限处理后的最终审批决定，避免自动允许后仍显示 ASK。UI 合约测试使用
临时目录，不再向真实 `data/approvals.json` 写入测试请求。
