## 根据实测修改

- 已完成 Gate 评分的失败构建也打开本轮视觉诊断检查点，允许通过返回的
  artifact_id 查看保存的场景。写入或重新尝试构建后失效，下一轮重置；不改变
  Gate 成功条件，也不把失败场景当成完成证据。
- 跨版本恢复提示只针对最新评分仍在失败的类别。保留历史统计，但修复成功后
  不再要求模型继续修复已经消失的 solid_count 错误。
- 在统一装配契约和 assembly 帮助中解释 assemble / explode / motion 的区别，
  并提示旋转轴应与实际轴几何对齐、变化的干涉不能直接解释为装配配合。
  内容适用于一般装配，没有加入直升机专用建模步骤。
- 有用户请求上下文时，在模型补丁落盘之前检查新增 confirmed 约束的原话来源
  和数值。首轮模型自创“两处关节是用户确认要求”后产生了错误阻塞；现在会原子
  拒绝这种确认，把设计假设保留为未确认约束。旧约束的保留和无请求上下文的
  程序化建模仍兼容。
- 实测运行器按最终 artifact_id 收集实际成功导出的 GIF，逐帧解码并记录模式；
  静态原生装配也可以交付 assemble 动画。增加指定模式验收和动画 HTTP 下载
  检查，避免旧版本文件、单帧文件或错误模式被算作交付成功。

## 产物检查与限制

复测模型包含一体机身/尾梁/滑橇、独立桅杆、主旋翼和尾旋翼。检查 assemble GIF
的首帧、中间帧、末帧，零件由分散位置合拢到保存姿态；检查 motion GIF 的
0、7、21 帧，两旋翼分别转动。全部原生帧中机身和桅杆矩阵不变；主旋翼轴为 Z，
尾旋翼轴为 Y，与配方轴一致。模型测量为 4 个有效实体，STEP 往返与导出通过。

模型自己检查的三对零件（主旋翼/机身、尾旋翼/机身、主旋翼/桅杆）在 61 个
采样帧的 BRep 重叠为零。这不能证明所有零件对的连续间隙，也不能证明安装
结构有效。机身仍是矩形简化外壳，没有玻璃座舱、垂尾、真实传动与完整轴承
安装结构，旋翼和支撑的实际配合需要进一步设计。用户没有给出可测尺寸，
两次都保持待验收概念草稿；本报告不将其标记为工程设计验收通过。

复测场景及 FCStd / STEP / STL HTTP 路径均返回 200。最终增加的 HTTP 动画
检查使用同一份已生成产物回放，未再次调用模型；两段 GIF 返回 200，响应字节
与磁盘文件一致，严格 assemble 与 motion 交付条件均通过。
